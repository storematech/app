# Quiz Maker — Native Android App (Phase 1)

A from-scratch native Android client (Kotlin + Jetpack Compose + MVVM) for
[Quiz Maker](https://quiz-maker.online), talking directly to the same
production Supabase backend the website uses — no WebView, no separate
custom API server.

See `.claude/plans` conversation history for the full architecture/migration
plan this was built from. Short version:

- **UI**: Jetpack Compose + Material 3
- **Architecture**: MVVM — Composable → ViewModel (StateFlow) → Repository → Supabase SDK
- **DI**: Hilt
- **Backend**: [supabase-kt](https://github.com/supabase-community/supabase-kt) talking to the
  same Supabase project as the web app (`src/integrations/supabase/client.ts` in the web repo)
- **Modules built (Phase 1 complete)**: Auth (sign up / sign in / forgot password),
  Dashboard, Quiz List, Quiz Creation (details → questions → settings → review),
  Quiz Details (share link + QR code), shareable-link deep linking, Take Quiz
  (guest flow with optional email-OTP verification and single/multi-attempt
  enforcement), Leaderboard, and Profile/Settings.

## Toolchain note

Versions were picked and cross-checked against Maven Central / Google's repository on
2026-08-06: AGP 8.13.2, Kotlin 2.2.20, supabase-kt 3.2.3, Gradle 8.14.5. Newer major
versions existed at the time (AGP 9.x, Kotlin 2.4.x) but were skipped deliberately —
they're recent enough that their exact DSL wasn't independently verifiable here, so the
safer, still-current choice was a version one step back from the bleeding edge. If you
want to move to AGP 9 / Kotlin 2.4+, Android Studio's Upgrade Assistant is the safest way
to do it incrementally.

## Getting started

1. Open this folder in Android Studio (Ladybug or newer recommended).
2. Let it sync — it will prompt to download Android SDK Platform 36 and matching build
   tools if they're not already installed.
3. This repo does **not** include committed `gradlew`/`gradlew.bat` wrapper scripts or the
   wrapper jar (they weren't generated by a real Gradle run in the environment this was
   built in). Android Studio will regenerate them automatically on first sync, or run:
   ```
   gradle wrapper --gradle-version 8.14.5
   ```
   if you have a system Gradle install.
4. Run the `app` configuration on an emulator or device (minSdk 24).

## Backend

The app points at Quiz Maker's real production Supabase project (same URL/anon key the
website uses — see `app/build.gradle.kts` `buildConfigField`s). Sign up/sign in with a
real account to see real data; there is no mock/staging mode in Phase 1.
